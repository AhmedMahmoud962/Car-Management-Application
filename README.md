# 🚗 Car Management Application

## 📌 Project Description
A **Car Management Application** built with **React**, allowing users to efficiently manage cars by adding, viewing, updating, and deleting car details. The app is fully responsive and provides a smooth user experience using **MUI, React Router DOM, and Redux**.

## 🚀 Features
- 🆕 **Add a new car**
- 🗑️ **Delete an existing car**
- 🔍 **View detailed information about each car**
- ✏️ **Update car details**
- 📱 **Fully responsive design for all devices**

## 🛠️ Technologies Used
- **React** ⚛️
- **MUI (Material-UI)** 🎨
- **React Router DOM** 🔀
- **Redux** 🗂️

## 📥 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AhmedMahmoud962/Car-Management-Application.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the application:**
   ```bash
   npm start
   ```
